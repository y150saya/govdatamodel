# 4.2 建物クラス図

建物モデルを「共通基盤」と「ドメイン別関係」に分けて定義します。

## 4.2.1 共通基盤（Base & Components）

すべての建物の基底となる共通クラスの定義です。

```mermaid
classDiagram
    direction TB

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }
```

---

## 4.2.2 ドメイン別関係

### 4.2.2.1 建物モデル

建物の物理的な形状・構造、用途、付随する住所や設備情報、および関連する各種コードリストの定義です。
* 建物種別は、[建築基準法施行規則別記様式](https://www.mlit.go.jp/statistics/details/content/001846694.pdf)の建築物用途区分項目を参照して定義します。
* 建物用途は、[都市計画基礎調査実施要領](https://www.mlit.go.jp/toshi/tosiko/kisotyousa001.html)の建物用途利用現況の用途分類を参照して定義します。
* 構造は、不動産登記規則第114条における「構成材料」「屋根の種類」「階数」の区分に準拠します。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    %% ---------------------------------------------------------
    %% クラス定義
    %% ---------------------------------------------------------
    class 建物_Building {
        + ID / id : ID（文字列） [0..1]
        + 建物種別 / buildingType : コード（文字列） [0..1]
          %% 建築基準法施行規則・別記様式の建築物用途区分項目に準拠
        + 名称 / name : 多言語表記型_Multilingual [0..1]
        + 通称 / alternateName : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
        + 備考 / remark : 文字列 [0..1]
        + 概要 / abstract : 文字列 [0..1]
        + 状態 / status : 文字列 [0..1]
        + 性能 / performanceDescription : 文字列 [0..1]
        + 建築面積 / buildingFootprintArea : 数値(実数) [0..1]
          %% 基準単位: m2
        + 延べ面積 / totalFloorArea : 数値(実数) [0..1]
          %% 基準単位: m2
        + 最高高さ / maximumHeight : 数値(実数) [0..1]
          %% 基準単位: m
        + 地上階数 / storeysAboveGround : 数値（整数） [0..1]
          %% 基準単位: 階   
        + 地下階数 / storeysBelowGround : 数値（整数） [0..1]
          %% 基準単位: 階
        + 竣工日 / dateOfCompletion : 日付 [0..1]
        %% 将来 + 不動産ID / realEstateId : ID（文字列） [0..1]
          %% ※国土交通省「不動産IDルールガイドライン」に準拠した17桁のコード
          %% （法務省の不動産登記規則に基づく13桁の不動産番号 ＋ 特定コード4桁）
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 建物種別_BuildingType <<CodeList>> {
            一戸建ての住宅
            長屋
            共同住宅
            ...
            %% ※詳細は建築基準法施行規則別記様式参照
        }

        class 建物用途分類_BuildingUsageCategory <<CodeList>> {
            %% 都市計画基礎調査実施要領の建物利用現況の用途分類に準拠する。
            401 : 業務施設
            402 : 商業施設
            403 : 宿泊施設
            404 : 商業系用途複合施設
            411 : 住宅
            412 : 共同住宅
            413 : 店舗等併用住宅
            414 : 店舗等併用共同住宅
            415 : 作業所併用住宅
            421 : 官公庁施設
            422 : 文教厚生施設
            431 : 運輸倉庫施設
            441 : 工場
            451 : 農林漁業用施設
            452 : 供給処理施設
            453 : 防衛施設
            454 : その他
            461 : 不明
            471 : 空家等
        }

        class 建物構造_BuildingStructure <<CodeList>> {
            %% 不動産登記規則第114条における「構成材料」「屋根の種類」「階数」の区分に準拠
            %% 階層を'_'で表現。
            構成材料_木造
            構成材料_土蔵造
            構成材料_石造
            構成材料_れんが造
            構成材料_コンクリートブロック造
            構成材料_鉄骨造
            構成材料_鉄筋コンクリート造
            構成材料_鉄骨鉄筋コンクリート造
            屋根の種類_かわらぶき
            屋根の種類_スレートぶき
            屋根の種類_亜鉛メッキ鋼板ぶき
            屋根の種類_草ぶき
            屋根の種類_陸屋根
            階数_平屋建
            階数_二階建
            %% 三階建て以上の建物にあっては、二階建てに準ずる
        }
    }

    namespace 共通クラス {
        class 住所_Address
        class 連絡先_ContactPoint
        class 設備_Equipment
        class 土地_Land
        class アクセシビリティ_Accessibility
        class 関連組織_RelatedOrganization

        %% 共通の構造体（言語）
        class 多言語表記型_Multilingual <<DataType>> {
            + 日本語 / ja : 文字列 [1]
            + カナ / kana : 文字列 [0..1]
            + 英字 / en : 文字列（半角） [0..1]
        }
    }


    %% 汎化（継承）
    AbstractSmartCityBase <|-- 建物_Building : 継承

    %% コンポジション（関係性の定義）
    建物_Building *-- "1" 住所_Address : 建物住所_buildingAddress
    建物_Building *-- "0..*" 連絡先_ContactPoint : 連絡先情報_contactPoint
    建物_Building *-- "0..*" アクセシビリティ_Accessibility : アクセシビリティ情報_accessibilityInformation
    建物_Building *-- "0..*" 関連組織情報_RelatedOrganizationInformation : 関連組織_relatedOrganization
    建物_Building "1" *-- "0..*" 多言語表記型_Multilingual : 名称

    %% リレーション
    建物_Building --> "0..*" 建物_Building : 関連建物_relatedBuilding
    建物_Building --> "0..*" 設備_Equipment : 設備情報_equipmentInformation
    建物_Building --> "0..1" 土地_Land : 敷地_site
    建物_Building "1" --> "0..1" 建物種別_BuildingType : 建物種別_buildingType
    建物_Building "1" --> "0..*" 建物用途分類_BuildingUsageCategory : 建物用途_buildingUsage
    建物_Building "1" --> "0..*" 建物構造_BuildingStructure : 建物構造_buildingStructure
```
