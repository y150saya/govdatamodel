# 4.5 建物内・地下街・地下埋設物クラス図

建物内・地下街・地下埋設物モデルを「共通基盤」および「ドメイン別継承関係」に分けて定義します。

## 4.5.1 共通基盤

本モデルに特化した固有の共通基盤クラスは存在しないため、基本共通クラスである `AbstractSmartCityBase` を継承します。

```mermaid
classDiagram
    direction TB

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }
```

---

## 4.5.2 ドメイン別継承関係

本モデルは主に既存の3D都市モデル（PLATEAU）や、国土交通省の電子納品要領などの外部仕様を参照する外部クラス（`<<External>>`）として位置づけられます。

* 建物内は[3D都市モデル標準製品仕様書 bldg:Building](https://www.mlit.go.jp/plateaudocument/toc4/toc4_02/toc4_02_03/) を参照することができます。なお、建物内の施設は施設のデータモデル、設備は設備のデータモデルで表現します。
* 地下街は[3D都市モデル標準仕様書 uro:UndergroundBuilding](https://www.mlit.go.jp/plateaudocument/toc4/toc4_16/) を参照することができます。なお、地下街の施設は施設のデータモデル、設備は設備のデータモデルで表現します。
* 地下埋設物は[3D都市モデル標準仕様書 uro:UtilityNetworkElement](https://www.mlit.go.jp/plateaudocument/toc4/toc4_15/) を参照することができます。
* ボーリング柱状図は[国土交通省 地質・土質調査成果電子納品要領](https://www.cals-ed.go.jp/cri_point/) の「第2編ボーリング柱状図編　5ボーリング交換用データ」及び「第6編土質試験及び地盤調査編　6土質試験結果一覧表データ」を参照することができます。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    class 建物内_BuildingInterior {
        <<External>>
        %% 3D都市モデル標準製品仕様書: bldg:Building
    }

    class 地下街_UndergroundBuilding {
        <<External>>
        %% 3D都市モデル標準仕様書: uro:UndergroundBuilding
    }

    class 地下埋設物_UndergroundBuriedObject {
        <<External>>
        %% 3D都市モデル標準仕様書: uro:UtilityNetworkElement
    }

    class ボーリング柱状図_BoringLog {
        <<External>>
        %% 国土交通省 地質・土質調査成果電子納品要領
        %% （第2編ボーリング柱状図編 5ボーリング交換用データ / 第6編土質試験及び地盤調査編 6土質試験結果一覧表データ）
    }

    namespace 関連外部クラス {
        class 施設_Facility {
            <<External>>
        }
        class 設備_Equipment {
            <<External>>
        }
    }

    %% 汎化（継承関係）
    AbstractSmartCityBase <|-- 建物内_BuildingInterior : 継承
    AbstractSmartCityBase <|-- 地下街_UndergroundBuilding : 継承
    AbstractSmartCityBase <|-- 地下埋設物_UndergroundBuriedObject : 継承
    AbstractSmartCityBase <|-- ボーリング柱状図_BoringLog : 継承

    %% 参照関係
    建物内_BuildingInterior "1" --> "0..*" 施設_Facility : 内包施設
    建物内_BuildingInterior "1" --> "0..*" 設備_Equipment : 内包設備

    地下街_UndergroundBuilding "1" --> "0..*" 施設_Facility : 内包施設
    地下街_UndergroundBuilding "1" --> "0..*" 設備_Equipment : 内包設備
```
