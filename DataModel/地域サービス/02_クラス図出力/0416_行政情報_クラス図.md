# 4.16 行政情報クラス図

行政情報モデルを「共通基盤」および「ドメイン別関係」に分けて定義します。
行政情報モデルは、地域統計を表す「地域・年齢別人口」と、行政サービス全般のデジタル化を支える「行政実装データモデル（デジタル庁 GIF 451準拠）」で構成されます。

## 4.16.1 共通基盤

行政情報モデルの基本クラスである `行政情報_AdministrativeInformation` は、基本共通クラスである `AbstractSmartCityBase` を継承します。

```mermaid
classDiagram
    direction TB

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }

    class 行政情報_AdministrativeInformation {
        + 地方公共団体コード / localGovernmentCode : コード（文字列） [0..1]
        + 更新年月日 / dateModified : 日付 [0..1]
    }

    %% 汎化（継承関係）
    AbstractSmartCityBase <|-- 行政情報_AdministrativeInformation : 継承
```

### 4.16.2.2 行政実装データモデル（GIF 451準拠）
