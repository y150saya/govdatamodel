# 4.15 文化財クラス図

文化財モデルを「共通基盤」および「ドメイン別関係」に分けて定義します。
本ドメインモデルでは、文化財指定情報を表す「文化財_CulturalProperty」を主に配置し、有形文化財の場合は「建物」「施設」「移動オブジェクト」「地物・地点」の物理オブジェクトを関連（参照）しています。これにより、無形文化財と有形文化財を一元管理しつつ、物理オブジェクトの特性を柔軟にマッピングできます。

## 4.15.1 共通基盤

文化財モデルの基本クラスである `文化財_CulturalProperty` は、基本共通クラスである `AbstractSmartCityBase` を継承します。

```mermaid
classDiagram
    direction TB

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }
```

## 4.15.2 ドメイン別関係

### 4.15.2.1 文化財

文化財モデルにおけるクラス定義と関係性です。

#### 4.15.2.2.1 通常クラス

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    %% ---------------------------------------------------------
    %% 外部ドメインの物理オブジェクトクラス（参照用）
    %% ---------------------------------------------------------
    namespace 物理エンティティ {
        class 建物_Building {
            + ID / id : ID（文字列） [0..1]
        }
        class 施設_Facility {
            + ID / id : ID（文字列） [0..1]
        }
        class 移動オブジェクト_MovingFeature {
            + ID / id : ID（文字列） [0..1]
        }
        class 地物地点_FeaturePoint {
            + ID / id : ID（文字列） [0..1]
        }
    }

    %% ---------------------------------------------------------
    %% 共通パーツ（Components）
    %% ---------------------------------------------------------
    namespace 共通クラス {
        class 住所_Address
        class 連絡先_ContactPoint
        class 多言語表記型_Multilingual <<DataType>>{
           + 日本語 / ja : 文字列 [1]
           + カナ / kana : 文字列 [0..1]
           + 英字 / en : 文字列（半角） [0..1]
        }
    }

    %% ---------------------------------------------------------
    %% クラス定義
    %% ---------------------------------------------------------
    class 文化財_CulturalProperty {
        + ID / id : ID（文字列） [0..1]
          %% 国立奈良文化財研究所・全国文化財総覧の日本全国文化財番号(JC番号)
        + 都道府県 / prefecture : 文字列（全角） [0..1]
        + 市区町村 / city : 文字列 [0..1]
        + 名称 / name : 多言語表記型_Multilingual [0..1]
        + 通称 / alternateName : 文字列 [0..*]
        
        %% 対象物理エンティティ用ID
        + 対象建物ID / buildingId : ID（文字列） [0..1]
          %% 紐づく建物ID
        + 対象施設ID / facilityId : ID（文字列） [0..1]
          %% 紐づく共通施設ID
        + 対象移動オブジェクトID / movingFeatureId : ID（文字列） [0..1]
          %% 紐づく移動オブジェクトID
        + 対象地物地点ID / featurePointId : ID（文字列） [0..1]
          %% 紐づく地点ID

        + 文化財分類 / culturalPropertyCategory : 文字列 [1..*]
          %% デジタル庁・自治体標準オープンデータセットの文化財分類
        + 文化財種別 / culturalPropertyType : コード（文字列） [0..*]
          %% 国立奈良文化財研究所・全国文化財総覧の文化財種別
        + 場所名称 / placeName : 文字列 [0..1]
        + 法人番号 / legalEntityNumber : ID（文字列） [0..1]
        + 所蔵機関等 / managingOrganization : 文字列 [0..*]
        + 文化財指定年月日 / designationDate : 日付 [0..1]
        + 指定者種別 / designationAuthority : 文字列 [0..*]
        + 指定登録分類 / designationRegistrationCategory : 文字列 [0..*]
        + 画像 / image : URI [0..*]
        + 説明 / description : 文字列 [0..1]
        + キーワード / keywords : 文字列 [0..*]
        + URL / url : URI [0..1]
        + 備考 / remark : 文字列 [0..1]
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 文化財分類_CulturalPropertyCategory <<CodeList>> {
            %% デジタル庁・自治体標準オープンデータセットの文化財分類
            %% 有形文化財
            重要文化財
            国宝
            登録有形文化財
            %% 無形文化財
            重要無形文化財
            記録作成等の措置を講ずべき無形文化財
            %% 有形民俗文化財
            重要有形民俗文化財
            登録有形民俗文化財
            %% 無形民俗文化財
            重要無形民俗文化財
            記録作成等の措置を講ずべき無形の民俗文化財
            %% 記念物
            史跡
            特別史跡
            名勝
            特別名勝
            天然記念物
            特別天然記念物
            登録記念物
            %% 文化的景観
            重要文化的景観
            %% 伝統的建造物群
            伝統的建造物群保存地区
            重要伝統的建造物群保存地区
            %% 遺跡
            埋蔵文化物
            %% その他
            その他
        }

        class 文化財種別_CulturalPropertyType <<CodeList>> {
            %% 国立奈良文化財研究所・全国文化財総覧の文化財種別
            史跡
            天然記念物
            建造物
            絵画
            彫刻
            工芸品
            美術工芸品
            書籍典籍
            歴史資料
            考古資料
            埋蔵文化財
            有形文化財
            無形文化財
            芸能
        }
    }

    %% 汎化（継承関係）
    AbstractSmartCityBase <|-- 文化財_CulturalProperty : 継承

    %% 物理エンティティへの関連（IDを介した参照関係）
    文化財_CulturalProperty "0..*" --> "0..1" 建物_Building : buildingIdで紐付け
    文化財_CulturalProperty "0..*" --> "0..1" 施設_Facility : facilityIdで紐付け
    文化財_CulturalProperty "0..*" --> "0..1" 移動オブジェクト_MovingFeature : movingFeatureIdで紐付け
    文化財_CulturalProperty "0..*" --> "0..1" 地物地点_FeaturePoint : featurePointIdで紐付け

    %% 共通パーツへの関連
    文化財_CulturalProperty *-- "0..1" 住所_Address : 所在住所
    文化財_CulturalProperty *-- "0..*" 連絡先_ContactPoint : 連絡先情報
    文化財_CulturalProperty *--> "0..1" 多言語表記型_Multilingual : 名称

    %% コードリストへの関連
    文化財_CulturalProperty "1" --> "1..*" 文化財分類_CulturalPropertyCategory : 文化財分類
    文化財_CulturalProperty "1" --> "0..*" 文化財種別_CulturalPropertyType : 文化財種別
```

#### 4.15.2.2.2 物理エンティティ主体モデル（アソシエーションによる結合）

建物、施設などを主体（親）とし、文化財情報を関連で紐付けるモデル案です。
物理オブジェクトが属性として文化財ID（culturalPropertyId）を持つことで、それぞれの実体に文化財の情報を関連付けます。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase
    class 文化財_CulturalProperty

    %% ---------------------------------------------------------
    %% 物理エンティティクラス
    %% ---------------------------------------------------------
    class 建物_Building {
        + 文化財ID / culturalPropertyId : ID（文字列） [0..1]
          %% 国立奈良文化財研究所・全国文化財総覧の日本全国文化財番号(JC番号)
    }
    class 施設_Facility {
        + 文化財ID / culturalPropertyId : ID（文字列） [0..1]
          %% 国立奈良文化財研究所・全国文化財総覧の日本全国文化財番号(JC番号)
    }
    class 移動オブジェクト_MovingFeature {
        + 文化財ID / culturalPropertyId : ID（文字列） [0..1]
          %% 国立奈良文化財研究所・全国文化財総覧の日本全国文化財番号(JC番号)
    }
    class 地物地点_FeaturePoint {
        + 文化財ID / culturalPropertyId : ID（文字列） [0..1]
    }


    %% ---------------------------------------------------------
    %% クラス定義
    %% ---------------------------------------------------------
    class 文化財_CulturalProperty {
        + ID / id : ID（文字列） [0..1]
    }

    %% 汎化（継承関係）
    AbstractSmartCityBase <|-- 建物_Building : 継承
    AbstractSmartCityBase <|-- 施設_Facility : 継承
    AbstractSmartCityBase <|-- 移動オブジェクト_MovingFeature : 継承
    AbstractSmartCityBase <|-- 地物地点_FeaturePoint : 継承
    AbstractSmartCityBase <|-- 文化財_CulturalProperty : 継承
    
    %% 物理エンティティから文化財へのアソシエーション（関連）
    建物_Building "0..*" --> "0..1" 文化財_CulturalProperty : 文化財IDで紐付け
    施設_Facility "0..*" --> "0..1" 文化財_CulturalProperty : 文化財IDで紐付け
    移動オブジェクト_MovingFeature "0..*" --> "0..1" 文化財_CulturalProperty : 文化財IDで紐付け
    地物地点_FeaturePoint "0..*" --> "0..1" 文化財_CulturalProperty : 文化財IDで紐付け
```
