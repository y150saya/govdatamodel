# 4.8 地物・地点クラス図

地物・地点モデルを「共通基盤」および「ドメイン別継承関係」に分けて定義します。

## 4.8.1 共通基盤（Base & Components）

すべての地物・地点の基底となる共通属性および、基本モデルである「土地」「建物」の定義です。

```mermaid
classDiagram
    direction TB   

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }

    %% ---------------------------------------------------------
    %% 土地（Base Class）
    %% ---------------------------------------------------------
    class 土地_Land {
        + ID / id : ID（文字列） [0..1]
          %% 法務省の筆コード（登記所備付地図）等の土地識別子の利用を想定。または、法務省の不動産登記規則に基づく13桁の不動産番号
        + 用途 / usage : コード（文字列） [1..*]
          %% 国土交通省都市局の都市計画基礎調査実施要領の土地利用現況の土地利用分類
        + 名称 / name : 多言語表記型_Multilingual [0..1]
        + 通称 / alternateName : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
        + 土地面積 / landArea : 数値（物理量） [0..1]
          %% 単位: m2
        + 土地形状イメージURL / landFormImageUrl : URI [0..1]
        + 備考 / remark : 文字列 [0..1]
        + 不動産ID / realEstateId : ID（文字列） [0..1]
          %% ※国土交通省「不動産IDルールガイドライン」に準拠した17桁のコード
          %% （法務省の不動産登記規則に基づく13桁の不動産番号 ＋ 特定コード4桁）
        %% --- 地理空間座標属性 ---
        + 土地形状 / landForm : ジオメトリ（面2D） [0..1]
        + 座標参照系 / coordinateReferenceSystem : 文字列 [0..1]
        + 座標参照系コード / coordinateReferenceSystemCode : コード（文字列） [0..1]
    }

    %% ---------------------------------------------------------
    %% 共通パーツ（Components）
    %% ---------------------------------------------------------
    namespace 共通クラス {
        class 住所_Address
        class 連絡先_ContactPoint

        %% 共通の構造体（言語）
        class 多言語表記型_Multilingual <<DataType>> {
            + 日本語 / ja : 文字列 [1]
            + カナ / kana : 文字列 [0..1]
            + 英字 / en : 文字列（半角） [0..1]
        }
    }

    %% 継承関係
    AbstractSmartCityBase <|-- 地物地点_FeaturePoint : 継承
    AbstractSmartCityBase <|-- 土地_Land : 継承

    %% コンポジション・参照関係
    土地_Land *-- "1" 住所_Address : 土地住所_landAddress
    土地_Land *-- "0..1" 連絡先_ContactPoint : 連絡先情報_contactPoint
    土地_Land "1" *-- "0..*" 多言語表記型_Multilingual : 名称
```

## 4.8.2 ドメイン別継承関係

地物・地点モデルの各サブカテゴリにおける固有のクラス定義と関係性です。

### 4.8.2.1 構造物・地物

建物や土地に類する「その他構造物」や、POIとしての「観光ポイント」、代表的な経緯度情報を保持する汎用的な「その他地点」のモデルです。

```mermaid
classDiagram
    direction TB
    class 地物地点_FeaturePoint

    class 建物_Building {
        <<External>>
    }

    class その他構造物_OtherStructure {
        + 構造物種別 / otherStructureType : コード（文字列） [0..1]
          %% デジタル庁 POIコード（地理的目標物分類コード）
    }

    class 観光ポイント_TouristAttraction {
        + 名称 / name : 多言語表記型_Multilingual [0..1]
        + 説明 / description : 文字列 [0..1]
    }

    class その他地点_OtherPlace {
        %% 任意の代表点等の座標情報を保持する基本クラス
    }

    namespace 共通クラス {
        class 住所_Address

        %% 共通の構造体（言語）
        class 多言語表記型_Multilingual <<DataType>> {
            + 日本語 / ja : 文字列 [1]
            + カナ / kana : 文字列 [0..1]
            + 英字 / en : 文字列（半角） [0..1]
        }

    }

    %% 汎化「親 (左) <|-- 子 (右)」
    建物_Building <|-- その他構造物_OtherStructure : 継承
    地物地点_FeaturePoint <|-- 観光ポイント_TouristAttraction : 継承
    地物地点_FeaturePoint <|-- その他地点_OtherPlace : 継承

    %% コンポジション・参照関係
    建物_Building --> "0..*" その他構造物_OtherStructure : 関連建物

    観光ポイント_TouristAttraction *-- "0..1" 住所_Address : 住所_address
    観光ポイント_TouristAttraction "1" *--> "0..*" 多言語表記型_Multilingual : 内包
```

### 4.8.2.2 防災 ※要修正

> [!NOTE]
> 記載箇所は地物地点から移動すべき内容

避難所情報を持つ「指定緊急避難場所」など、防災に関する地物・地点モデルです。
防災は内閣府より公表されている災害対応基本共有情報（EEI）を参照します。
「指定緊急避難場所」については、データ連携や物理設計に合わせられるよう、各災害種別ごとの対応有無をカラムとして展開した「横持ち形式（フラットスキーマ）」と、災害種別を行に展開した「縦持ち形式（ノーマライズスキーマ）」の2パターンを選択可能なモデルとして整理しています。

```mermaid
classDiagram
    direction TB
    class 施設_Facility

    class 指定緊急避難場所_DesignatedEmergencyShelter {
        + 指定避難所重複有無 / designatedShelterOverlapStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 想定収容人数 / expectedCapacityPersonCount : 数値（物理量） [0..1]
          %% 単位: 人
        + 対象町会・自治会 / targetNeighborhoodAssociation : 文字列 [0..*]
          %% セミコロン区切りで記載
    }

    class 指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal {
        + 洪水対応有無 / floodSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 崖崩れ等対応有無 / landslideSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 高潮対応有無 / stormSurgeSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 地震対応有無 / earthquakeSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 津波対応有無 / tsunamiSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 大規模火災対応有無 / largeScaleFireSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 内水氾濫対応有無 / inlandFloodSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
        + 火山対応有無 / volcanoSupportStatus : コード（文字列） [0..1]
          %% 有無コード参照
    }

    class 指定緊急避難場所_縦持ち_DesignatedEmergencyShelterVertical {
        + 災害種別 / disasterType : 文字列 [0..*]
          %% 災害種別リストからの選択
        + 該当有無 / applicableStatus : コード（文字列） [0..1]
          %% 有無コード参照
    }

    namespace コード_リスト定義 {
        class 有無コード_StatusCode <<Enumeration>> {
            0 : 無
            1 : 有
            2 : 非公開
            9 : 不明
        }

        class 災害種別_disasterType <<CodeList>> {
            %% 災害対策基本法の指定緊急避難場所の対象となる災害種別
            地震
            津波
            洪水
            内水氾濫
            土砂災害
            高潮
            火山現象
            大規模な火事
            暴風・竜巻
            雪害
            干ばつ・渇水
            その他災害
        }
    }

    %% 継承関係
    施設_Facility <|-- 指定緊急避難場所_DesignatedEmergencyShelter : 継承
    指定緊急避難場所_DesignatedEmergencyShelter <|-- 指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal : 継承
    指定緊急避難場所_DesignatedEmergencyShelter <|-- 指定緊急避難場所_縦持ち_DesignatedEmergencyShelterVertical : 継承

    %% 参照関係
    指定緊急避難場所_DesignatedEmergencyShelter "1" --> "0..1" 有無コード_StatusCode : 指定避難所重複有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 洪水対応有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 崖崩れ等対応有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 高潮対応有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 地震対応有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 津波対応有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 大規模火災対応有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 内水氾濫対応有無参照
    指定緊急避難場所_横持ち_DesignatedEmergencyShelterHorizontal "1" --> "0..1" 有無コード_StatusCode : 火山対応有無参照

    指定緊急避難場所_縦持ち_DesignatedEmergencyShelterVertical "1" --> "0..1" 有無コード_StatusCode : 該当有無参照
    指定緊急避難場所_縦持ち_DesignatedEmergencyShelterVertical "1" --> "0..1" 災害種別_disasterType : 災害種別
```

### 4.8.2.3 生活インフラ

生活に密着した「ゴミ集積場所」など、インフラ寄りの地物・地点モデルです。
データモデルはデジタル庁の自治体標準オープンデータセットを参照します。
ゴミ集積場所は、戸建て住宅地や集積ボックスなどの「施設（`施設_Facility`）」として定義される場合と、道路上のステーションや特定の集積エリアといった単なる「地点（`地物地点_FeaturePoint`）」として定義される場合があるため、双方の継承関係（多重継承）をモデル化しています。

```mermaid
classDiagram
    direction TB
    class 地物地点_FeaturePoint

    class ゴミ集積場所_WasteCollectionPoint {
        サービス / Service      
        + ゴミ種別 / wasteType : 文字列 [0..*]
        + 地区名 / districtName : 文字列 [0..1]
        + ゴミ収集日 / wasteCollectionSchedule : 文字列 [0..*]
        + 自治体URL / municipalServiceURL : URL [0..1]
    }

    namespace 共通クラス {
        class 施設_Facility
    }

    %% 継承関係
    施設_Facility <|-- ゴミ集積場所_WasteCollectionPoint : 継承
    地物地点_FeaturePoint <|-- ゴミ集積場所_WasteCollectionPoint : 継承
```
