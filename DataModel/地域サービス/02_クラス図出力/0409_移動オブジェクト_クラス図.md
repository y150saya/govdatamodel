# 4.9 移動オブジェクトクラス図

移動オブジェクトモデルを「共通基盤（Base）」に分けて定義します。

## 4.9.1 共通基盤（Base）

すべての移動オブジェクトの基底となる共通属性の定義です。

```mermaid
classDiagram
    direction TB   

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }

    %% ---------------------------------------------------------
    %% 移動オブジェクト共通（Base Class）
    %% ---------------------------------------------------------
    class 移動オブジェクト_MovingFeature {
        %% OGC/ISO : MovingFeatures、CityGML : MovingObject
        + ID / id : ID（文字列） [0..1]
        + 区分 / category : 文字列 [0..1]
          %% 移動オブジェクト区分リストからの選択
        + 高さ / height : 数値（実数） [0..1]
        + 長さ / length : 数値（実数） [0..1]
        + 幅 / width : 数値（実数） [0..1]
        + 重量 / weight : 数値（実数） [0..1]
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 移動オブジェクト区分_movingFeatureCategory <<CodeList>> {
            歩行者等
              %% 歩行者、車いす、電動車いす、シニアカーなど
            物
            自動車・大型車両
              %% 乗用車、タクシー、バス、トラック、特殊車両など
            鉄道・軌道
              %% 鉄道、LRT、新交通システムなど
            二輪・マイクロ
              %% オートバイ、自転車、電動キックボード、一般原付、パーソナルモビリティなど
            水上
              %% 船舶
            航空
              %% 航空機、ドローン
            その他
              %% 自動配送ロボットを含む
        }
    }

    %% 継承関係
    AbstractSmartCityBase <|-- 移動オブジェクト_MovingFeature : 継承

    %% リレーション
    移動オブジェクト_MovingFeature "1" --> "1" 移動オブジェクト区分_movingFeatureCategory : 区分
```

## 4.9.2 ドメイン別継承関係

移動オブジェクトの各サブカテゴリにおける固有のクラス定義と関係性です。

### 4.9.2.1 移動オブジェクトのサブカテゴリ

移動オブジェクトを「人」「乗り物」「物」に分類し、それぞれの持つ属性やコードリストとの関係性を定義します。

```mermaid
classDiagram
    direction TB

    %% 共通クラス
    class 移動オブジェクト_MovingFeature

    %% ---------------------------------------------------------
    %% サブクラス定義
    %% ---------------------------------------------------------
    class 人_Person {
        + 性別 / sex : コード（文字列） [0..1]
          %% ISO5218 性別コード参照
        + 年齢 / age : 数値（物理量） [0..1]
          %% 単位: 歳
        + 機能支援種別 / functionalSupportType : 文字列 [0..*]
          %% 機能支援種別リストからの選択
          %% 移動に特化するため、アクセシビリティと異なる。
    }

    class 乗り物_Vehicle {
        + 乗り物種別 / vehicleCategory : 乗り物種別_VehicleCategory [0..1]
          %% 乗り物種別リストからの選択
        + 乗り物小分類 / vehicleType : 乗り物小分類_VehicleType [0..1]
          %% 乗り物小分類リストからの選択。ただし、文字列にして自由記載とするか要検討。
        + 燃料種別 / fuelType : 文字列 [0..1]
          %% 燃料種別リストからの選択
        + 定員 / capacity : 数値（物理量） [0..1]
          %% 単位: 人
        + 積載量 / payload : 数値（物理量） [0..1]
          %% 単位: kg
        + 自動運転レベル / autonomousDrivingLevel : 文字列 [0..1]
          %% 自動運転レベル（0〜5など）
    }

    class 機能支援種別_FunctionalSupportType {
        + 視覚支援有無 / visualSupportStatus : コード（文字列） [0..1]
        + 聴覚支援有無 / hearingSupportStatus : コード（文字列） [0..1]
        + 移動支援有無 / mobilitySupportStatus : コード（文字列） [0..1]
        + その他支援有無 / otherSupportStatus : コード（文字列） [0..1]
    }

    class 物_Thing {
        %% 固有属性なし（移動オブジェクト_MovingFeatureの属性を使用）
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 性別コード_SexCode <<Enumeration>> {
            0 : 不明
            1 : 男性
            2 : 女性
            9 : 適用不能
        }

        class 有無コード_StatusCode <<Enumeration>> {
            0 : 無
            1 : 有
            2 : 非公開
            9 : 不明
        }

        class 乗り物種別_VehicleCategory <<CodeList>> {
            自動車・大型車両 / motorVehicle
            鉄道・軌道 / rail
            二輪 / twoWheeler
            マイクロモビリティ / micromobility
            歩行者等 / pedestrian
            水上 / water
            航空 / aviation
            物 / goods
            その他 / other
        }

        class 乗り物小分類_VehicleType <<CodeList>> {
            %% 自動車・大型車両
            乗用車 / car
            タクシー / taxi
            バス / bus
            トラック / truck
            特殊車両 / specialVehicle
            %% 鉄道・軌道
            鉄道 / train
            LRT / tram
            新交通システム / peopleMover
            %% 二輪
            オートバイ / motorcycle
            自転車 / bicycle
            一般原付 / moped
            %% マイクロモビリティ
            電動キックボード / eScooter
            パーソナルモビリティ / personalMobility
            %% 歩行者等
            車いす / wheelchair
            電動車いす / electricWheelchair
            シニアカー / mobility scooter
            %% 水上
            船舶 / ship
            フェリー / ferry
            %% 航空
            航空機 / aircraft
            ドローン / drone
            ヘリコプター / helicopter
            飛行船 / airship
            %% 物
            自動配送ロボット / deliveryRobot
            %% その他
            その他 / other
        }

        class 燃料種別_FuelType <<CodeList>> {
            ガソリン
            軽油
            重油
            LPG/CNG
            電気
            水素
            バイオ/合成燃料
            その他
        }
    }

    %% 汎化（継承関係）
    移動オブジェクト_MovingFeature <|-- 人_Person : 継承
    移動オブジェクト_MovingFeature <|-- 乗り物_Vehicle : 継承
    移動オブジェクト_MovingFeature <|-- 物_Thing : 継承

    %% 参照関係
    人_Person "1" *--> "0..*" 機能支援種別_FunctionalSupportType : 機能支援種別
    機能支援種別_FunctionalSupportType "1" --> "0..1" 有無コード_StatusCode : 支援有無
    人_Person "1" --> "0..1" 性別コード_SexCode : 性別
    乗り物_Vehicle "1" --> "0..1" 乗り物種別_VehicleCategory : 乗り物種別
    乗り物_Vehicle "1" --> "0..1" 乗り物小分類_VehicleType : 乗り物小分類
    乗り物_Vehicle "1" --> "0..1" 燃料種別_FuelType : 燃料種別
```

### 4.9.2.2 継承属性の解釈と単位定義

親クラス `移動オブジェクト_MovingFeature` から継承される属性について、各サブクラスにおける物理的な意味および使用される単位の定義は以下の通りです。

| 継承元属性 (MovingFeature) | 人 (Person) での物理的意味・単位 | 乗り物 (Vehicle) での物理的意味・単位 | 物 (Thing) での物理的意味・単位 |
| :--- | :--- | :--- | :--- |
| `id` | 一意のID（識別キー） | 一意のID（識別キー） | 一意のID（識別キー） |
| `height` | 身長（単位: cm） | 高さ（単位: m） | 高さ（単位: 実数） |
| `length` | - | 長さ（単位: m） | 長さ（単位: 実数） |
| `width` | - | 幅（単位: m） | 幅（単位: 実数） |
| `weight` | 体重（単位: kg） | 重量（単位: kg） | 重量（単位: 実数） |
