# 4.6 道路クラス図

道路モデルを「共通基盤」と「ドメイン別継承関係」に分けて定義します。

## 4.6.1 共通基盤（Base）

すべての道路の基底となるクラスの定義です。
共通基盤は国土数値情報の道路データ（ライン）を基本とします。
このデータモデルはノードとリンク、上下線や車線、高低差などのネットワーク構成を持たないため、ネットワーク構成が必要な場合は専門データモデルの参照が必要です。
道路の詳細モデルは[3D都市モデル標準製品仕様書](https://www.mlit.go.jp/plateaudocument/toc4/)　tran:roadおよび道路基盤地図情報製品仕様書（案）を参照してください。

※ UMLクラス図にプロパティの記載がありながら、例外処置としてコードにリレーションを取ります。

```mermaid
classDiagram
    direction TB   

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }

    %% ---------------------------------------------------------
    %% 道路共通（Base Class）
    %% ---------------------------------------------------------
    class 道路_Road {
        国土数値情報 道路
        + 道路地点 / roadPoint : 位置情報型 [0..*]
          %% 国土数値情報の場所_GM_Curve
        + 整備データ登録日 / maintenanceDataRegistrationDate : 日付 [0..1]
          %% 国土数値情報の整備データ登録日
        + 道路中心線種別 / roadCenterlineType : コード（文字列） [0..1]
          %% 国土数値情報の道路中心線種別コード
        + 道路分類種別 / roadClassificationType : コード（文字列） [0..1]
          %% 国土数値情報の道路分類種別コード
        + 道路状態種別 / roadStatusType : コード（文字列） [0..1]
          %% 国土数値情報の道路状態種別コードまたは3D都市モデル i-UR:TrackAttribute_structureType
        + 幅員区分 / roadWidthType : コード（文字列） [0..1]
          %% 国土数値情報の幅員区分コード
        + 有料区分 / tollClassificationType : コード（文字列） [0..1]
          %% 国土数値情報の有料区分コード
        %% --- 地理空間座標属性 ---
        %% 空間スキーマ型に座標参照系と座標参照系コードを組み入れて、関連させるか要検討。
        + 路線 / route : ジオメトリ（線） [0..*]
        + 座標参照系 / coordinateReferenceSystem : 文字列 [0..1]
        + 座標参照系コード / coordinateReferenceSystemCode : コード（文字列） [0..1]
        
        独自指定
        + 路線名 / routeName : 文字列 [0..1]
        + 通称 / alternateName : 文字列 [0..*]
        + 緊急輸送道路区分 / emergencyTransportationRoadType : コード（文字列） [0..1]
          %% 国土数値情報の緊急輸送道路区分コードもしくは3D都市モデル標準製品仕様書 Road_usageを使用。
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 道路中心線種別コード_RoadCenterlineCode <<CodeList>> {
            1 : 通常部
            2 : 庭園路
            3 : 徒歩道
            4 : 石段
            5 : 不明
        }

        class 道路分類種別コード_RoadClassificationCode <<CodeList>> {
            1 : 国道
            2 : 都道府県道
            3 : 市区町村道等
            4 : 高速自動車国道等
            5 : その他
            6 : 不明
        }

        class 道路状態種別コード_RoadStatusCode <<CodeList>> {
            1 : 通常部
            2 : 橋・高架
            3 : トンネル
            4 : 雪覆い
            5 : 建設中
            6 : その他
            7 : 不明
        }

        class 道路幅員区分コード_RoadWidthCode <<CodeList>> {
            1 : 3m未満
            2 : 3m以上5.5m未満
            3 : 5.5m以上13m未満
            4 : 13m以上19.5m未満
            5 : 19.5m以上
            6 : 不明
        }

        class 有料区分コード_TollClassificationCode <<CodeList>> {
            1 : 有料
            2 : 無料
        }
    }

    %% リレーション
    AbstractSmartCityBase <|-- 道路_Road
    道路_Road "1" --> "0..1" 道路中心線種別コード_RoadCenterlineCode : 道路中心線種別
    道路_Road "1" --> "0..1" 道路分類種別コード_RoadClassificationCode : 道路分類種別
    道路_Road "1" --> "0..1" 道路状態種別コード_RoadStatusCode : 道路状態種別
    道路_Road "1" --> "0..1" 道路幅員区分コード_RoadWidthCode : 道路幅員区分
    道路_Road "1" --> "0..1" 有料区分コード_TollClassificationCode : 有料区分
```

## 4.6.2 ドメイン別継承関係

### 4.6.2.1 道路地点・道路規制・インフラ
* 道路地点は道路のある地点を示す場合に利用します。
* 道路関連設備は[3D都市モデル標準製品仕様書 frn:CityFurniture](https://www.mlit.go.jp/plateaudocument/toc4/toc4_14/toc4_14_03/toc4_14_03_01/_ecc6aef8-ce50-ce44-989d-eccc33711712/) を参照することができます。
* 交通規制情報は[公益財団法人日本道路交通情報センターの公開する交通規制情報](https://www.jartic.or.jp/d/opendata/typeD_kisei_73_k_2.1.pdf) を参照することができます。JARTICの交通規制情報を利用しない簡単な規制（ネットワーク構成なし）を、道路規制情報として参考にクラス図にて記載します。
* 交通インフラは[3D都市モデル標準製品仕様書 橋梁モデル](https://www.mlit.go.jp/plateaudocument/toc4/toc4_11/)、[3D都市モデル標準製品仕様書 トンネルモデル](https://www.mlit.go.jp/plateaudocument/toc4/toc4_12/)などを参照することができます。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase
    class 設備_Equipment

    class 道路地点_RoadPoint {
        + 路線名 / routeName : 文字列 [0..1]
        + 地点 / point : ジオメトリ（点） [0..1]
        + 地点名 / pointName : 文字列 [0..1]
          %% 接続部（起点、終点、交差点等）などの名称
        + 状況 / roadStatus : 文字列 [0..1]
    }

    class 道路関連設備_RoadEquipment {
        <<External>>
        %% 3D都市モデル標準製品仕様書 frn:CityFurniture
    }

    class 道路規制情報_RoadRegulation {
        <<External>>
        %% 公益財団法人日本道路交通情報センターの公開する交通規制情報
        + ID / id : ID（文字列） [0..1]
        + 規制種別 / regulationType : 文字列 [0..1]
        + 路線名 / routeName : 文字列 [0..1]
        + 規制起点 / regulationStartPoint : 文字列 [0..1]
        + 規制終点 / regulationEndPoint : 文字列 [0..1]
        + 規制開始日時 / regulationStartDateTime : 日時 [0..1]
        + 規制終了予定日時 / regulationEndScheduledDateTime : 日時 [0..1]
        + 規制終了日時 / regulationEndDateTime : 日時 [0..1]
        + 規制原因 / regulationReason : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
        + 終日規制有無 / allDayRegulationStatus : コード（文字列） [0..1]
        + 規制時間帯 / regulationTimePeriod : 時間帯 [0..*]
        + 迂回路有無 / rerouteStatus : コード（文字列） [0..1]
        + 管理者 / organization : 文字列 [0..*]
        %% --- 地理空間座標属性 ---
        %% 空間スキーマ型に座標参照系と座標参照系コードを組み入れて、関連させるか要検討。
        + 路線 / route : ジオメトリ（線） [0..*]
        + 座標参照系 / coordinateReferenceSystem : 文字列 [0..1]
        + 座標参照系コード / coordinateReferenceSystemCode : コード（文字列） [0..1] 
    }

    class 交通インフラ_TrafficInfrastructure {
        <<External>>
        %% 3D都市モデル標準製品仕様書 橋梁モデル、トンネルモデル
    }

    %% ---------------------------------------------------------
    %% コード_リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 規制種別_regulationType <<CodeList>> {
            全面通行止め
            片側交互通行
            大型車両通行止め
            チェーン必要
            夜間通行止め
            時間帯全面通行止め
            片側通行止め
            車線減少
            その他規制
            規制なし
        }

        class 規制区分_regulationCategory <<CodeList>> {
            工事・作業
            災害等
            気象・事前規制
            事故・事象
            イベント
            その他
        }
    }

    %% 汎化（UML準拠継承）
    AbstractSmartCityBase <|-- 道路地点_RoadPoint : 継承
    設備_Equipment <|-- 道路関連設備_RoadEquipment : 継承
    AbstractSmartCityBase <|-- 道路規制情報_RoadRegulation : 継承
    AbstractSmartCityBase <|-- 交通インフラ_TrafficInfrastructure : 継承

    %% リレーション
    道路規制情報_RoadRegulation *-- "0..*" 連絡先_ContactPoint : 連絡先情報
    道路規制情報_RoadRegulation "1" --> "0..1" 規制種別_regulationType : 規制種別
    道路規制情報_RoadRegulation "1" --> "0..1" 規制区分_regulationCategory : 規制区分
```
