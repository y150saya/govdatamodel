# 4.7 交通関連施設クラス図

交通関連施設モデルを「共通基盤」および「ドメイン別継承関係」に分けて定義します。

## 4.7.1 共通基盤（Base & Components）

すべての交通関連施設の共通となる基底クラス（共通属性）および共通パーツの定義です。

```mermaid
classDiagram
    direction TB   

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }

    %% ---------------------------------------------------------
    %% 施設共通（Base Class）
    %% ---------------------------------------------------------
    class 施設_Facility {
        + ID / id : ID（文字列） [0..1]
        + 施設種別 / category : コード（文字列） [1]
        + 名称 / name : 多言語表記型_Multilingual [0..1]
        + 通称 / alternateName : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
        + アクセス方法 / accessMethod : 文字列 [0..1]
        + 駐車場有無 / parkingStatus : コード（文字列） [0..1]
        + 概要 / abstract : 文字列 [0..1]
        + 状態 / status : 文字列 [0..1]
        + 防災情報 / shelterInformation : 文字列 [0..1]
        + 利用可能曜日 / availableDay : 文字列 [0..1]
        + 開始時刻 / startTime : 時刻 [0..1]
        + 終了時刻 / endTime : 時刻 [0..1]
        + 利用可能日時説明 / availableDateTimeDescription : 文字列 [0..1]
        + 利用可能日時 / availableDateTime : 期間 [0..*]
        + 一般利用可否 / generalUserAvailability : コード（文字列） [0..1]
        + 収容人数 / capacity : 数値（物理量） [0..1]
          %% 単位:人
        施設の利用日時がサービスの利用日時になっているため、分離の必要があるか要検討
    }

    %% ---------------------------------------------------------
    %% 共通パーツ（Components）
    %% ---------------------------------------------------------
    namespace 共通クラス {
        class 住所_Address

        class 連絡先_ContactPoint

        class 設備_Equipment

        class アクセシビリティ_Accessibility

        %% class 子供預かり情報_childcare{
        %%     子育て支援施設か施設の配下か要検討
        %% }

        class 関連組織_RelatedOrganization

        class 料金情報_FeeInformation{
            各サービスか施設の配下か要検討
        }

        class 駐車場_ParkingFacility{
            サービスとしてのクラスを新設
        }

        %% 共通の構造体（言語）
        class 多言語表記型_Multilingual <<DataType>> {
            + 日本語 / ja : 文字列 [1]
            + カナ / kana : 文字列 [0..1]
            + 英字 / en : 文字列（半角） [0..1]
        }
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 有無コード_StatusCode <<Enumeration>> {
            0 : 無
            1 : 有
            2 : 非公開
            9 : 不明
        }

        class 可否コード_AvailabilityCode <<Enumeration>> {
            0 : 否
            1 : 可
            2 : 非公開
            9 : 不明
        }
    }

    %% リレーション
    AbstractSmartCityBase <|-- 施設_Facility
    施設_Facility *-- "1" 住所_Address : 施設住所_buildingAddress
    施設_Facility *-- "0..*" 連絡先_ContactPoint : 連絡先情報
    施設_Facility *-- "0..*" 設備_Equipment : 設備情報
    施設_Facility *-- "0..*" アクセシビリティ_Accessibility : アクセシビリティ情報
    %% 施設_Facility *-- "0..*" 子供預かり情報_childcare : 子供預かり情報
    施設_Facility *-- "0..*" 関連組織_RelatedOrganization : 関連組織情報
    施設_Facility *-- "0..*" 駐車場_ParkingFacility : 駐車場情報
    施設_Facility *-- "0..1" 料金情報_FeeInformation : 施設料金一覧_facilityFeeList
    施設_Facility --> "0..1" 施設_Facility : 関連施設_relatedFacility
    施設_Facility "1" --> "0..1" 有無コード_StatusCode : 有無参照
    施設_Facility "1" --> "0..1" 可否コード_AvailabilityCode : 可否参照
    施設_Facility "1" *--> "0..*" 多言語表記型_Multilingual : 内包
```

## 4.7.2 ドメイン別継承関係

交通関連施設の各サブカテゴリにおける固有のクラス定義と関係性です。

### 4.7.2.1 公共交通（GTFS-JP外部参照）

運行ダイヤや系統情報を持つ公共交通コアデータは、独自に定義せず[公共交通運行情報標準データ GTFS-JP](https://www.mlit.go.jp/sogoseisaku/transport/sosei_transport_tk_000067.html)を利用します。公共交通関連施設ですが、駅や停留所に関連する路線もここでは記載をしています。
クラス図上では `<<External>>` を付与し、GTFS-JP内の `stops.txt`（駅・バス停）および `routes.txt`（鉄道路線・バス路線）を参照する形に整理しています。
以下は参考までにGTFS-JP(stops.txt, routes.txt)の主要プロパティを記載します。GTFS-JP記載のスネークケースで表しています。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    class 停留所_駅_Stop {
        <<External>>
        %% GTFS-JP (stops.txt)
        %% 主要プロパティ
        + 停留所・駅ID / stop_id : ID（文字列） [1]
        + 停留所・駅名称 / stop_name : 文字列 [1]
        + 緯度 / stop_lat : 数値（実数） [1]
        + 経度 / stop_lon : 数値（実数） [1]
        + 位置区分 / location_type : コード（文字列） [1]
    }

    class 路線_Route {
        <<External>>
        %% GTFS-JP (routes.txt)
        %% 主要プロパティ
        + 路線ID / route_id : ID（文字列） [1]
        + 路線系統 / route_short_name : 文字列 [1]
        + 路線名称 / route_long_name : 文字列 [1]
        + 路線種別 / route_type : コード（文字列） [1]
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 路線種別_route_type <<CodeList>> {
            0 : 路面電車、ライトレール
            1 : 地下鉄
            2 : 鉄道
            3 : バス、デマンド型交通
            4 : フェリー、船舶
            5 : ケーブルトラム
            6 : ロープウェイ
            7 : ケーブルカー
            11 : トローリーバス
            12 : モノレール
        }

        class 位置区分_location_type <<CodeList>> {
            0 : 乗り場
            1 : 駅・バスターミナル
            2 : 出入口
            3 : 汎用ノード
            4 : 乗車エリア
        }
    }

    %% 継承関係 (施設ではなく、基底クラスを直接継承して軽量化)
    AbstractSmartCityBase <|-- 停留所_駅_Stop : 継承
    AbstractSmartCityBase <|-- 路線_Route   : 継承

    %% リレーション
    路線_Route "1" --> "0..1" 路線種別_route_type : 路線種別参照
    停留所_駅_Stop "1" --> "0..1" 位置区分_location_type : 位置区分参照
```

### 4.7.2.2 空港・港湾

施設の基本モデルを使用し、[国土数値情報](https://nlftp.mlit.go.jp/ksj/index.html)の空港、港湾を参照します。

```mermaid
    class 施設_Facility

    class 空港_Airport {
        <<External>>
        %% 国土数値情報 (Airport)
    }

    class 港湾_PortAndHarbor {
        <<External>>
        %% 国土数値情報 (PortAndHarbor)
    }

    %% 継承関係
    施設_Facility <|-- 空港_Airport : 継承
    施設_Facility <|-- 港湾_PortAndHarbor : 継承
```

### 4.7.2.3 駐車場・駐輪場

一般および路上の駐車スペース、駐輪場のモデル定義です。施設に関連する場合と関連しない場合があるため、独立の基本モデルとして定義します。
なお、荷捌きなど1台分の駐車スペースとして荷捌き駐車スペース、パーキングメーターなどの路上駐車スペースは駐車場の基本モデルを利用します。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    class 駐車場_ParkingFacility {
        + 対象車種 / targetVehicleType : 文字列 [0..*]
        + 最大駐車台数 / maxParkingCapacity : 数値（物理量） [0..1]
          %% 単位:台
        + 利用可能台数 / availableParkingCount : 数値（物理量） [0..1]
          %% 単位:台
        + 時間あたり入庫車数 / hourlyEntryCount : 数値（物理量） [0..1]
          %% 単位:台
        + 優先駐車場有無 / priorityParkingStatus : コード（文字列） [0..1]
          %% アクセシビリティにあるため、こちらに定義するか要検討。
        + 付帯設備 / ancillaryEquipment : 文字列 [0..*]
        + 料金有無 / feeStatus : コード（文字列） [0..1]
    }

    class 路上駐車スペース_OnStreetParkingSpace {
        + 許容時間 / allowableTime : 日時 [0..1]
    }

    class 荷さばき駐車スペース_LoadingZone {
        + 許容時間 / allowableTime : 日時 [0..1]
    }

    %% ---------------------------------------------------------
    %% 共通パーツ（Components）
    %% ---------------------------------------------------------
    namespace 共通クラス {
        class 住所_Address
        class 位置情報型_CommonLocation
        class 料金情報_FeeInformation{
            各サービスか施設の配下か要検討
        }
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 有無コード_StatusCode <<Enumeration>> {
            0 : 無
            1 : 有
            2 : 非公開
            9 : 不明
        }

        class 屋内外区分コード_IndoorOutdoorCategoryCode <<CodeList>> {
            屋内
            屋外
        }
    }

    %% 継承関係 (施設ではなく、基底クラスを直接継承して軽量化)
    AbstractSmartCityBase <|-- 駐車場_ParkingFacility : 継承
    駐車場_ParkingFacility <|-- 路上駐車スペース_OnStreetParkingSpace : 継承
    駐車場_ParkingFacility <|-- 荷さばき駐車スペース_LoadingZone : 継承

    %% コンポジション・参照関係
    駐車場_ParkingFacility *-- "0..1" 住所_Address : 駐車場住所_parkingAddress
    駐車場_ParkingFacility *-- "0..1" 位置情報型_CommonLocation : 位置情報参照
    駐車場_ParkingFacility *-- "0..1" 料金情報_FeeInformation : 駐車料金一覧_parkingFeeList

    駐車場_ParkingFacility "1" --> "0..1" 有無コード_StatusCode : 料金有無参照
    駐車場_ParkingFacility "1" --> "0..1" 屋内外区分コード_IndoorOutdoorCategoryCode : 屋内外区分参照
```

### 4.7.2.4 モビリティインフラ（給油・給電・シェア・タクシー）

各種給油・給電スポット、および施設を伴わない乗降・シェア用スポットの定義です。
EVスタンド（`EVスタンド_EVChargingStation`）は、ガソリンスタンドや駐車場の属性（ブランド、運営者、支払方法、車両容量など）を共有するため、`ガソリンスタンド_水素ステーション_GasStation` と `駐車場_ParkingFacility` を親クラスとする多重継承関係として定義しています。

※なお、EVスタンドを管理の主体（メインエンティティ）とする場合は、EVスタンド側に `parkingId`（対象駐車場ID）や `gasStationId`（対象ガソリンスタンドID）等の属性を持たせてアソシエーション（関連）で紐付けることも可能です。

```mermaid
classDiagram
    direction TB
    class 施設_Facility
    class 駐車場_ParkingFacility

    class ガソリンスタンド_水素ステーション_GasStation {
        + ブランド / network : 文字列 [0..1]
        + 対象車種 / allowedVehicleType : 文字列 [0..*]
        + 利用可能車両数 / availableCapacity : 数値（物理量） [0..1]
          %% 単位:台
        + 最大車両数 / capacity : 数値（物理量） [0..1]
          %% 単位:台
        + 燃料種別 / fuelType : 文字列 [0..*]
        + 支払方法 / acceptedPaymentMethod : 文字列 [0..*]
        + データ更新年月日 / dateModified : 日付 [0..1]
        + 運営者 / operator : 文字列 [0..1]
        + 所有者 / owner : 文字列 [0..1]
        + 備考 / remark : 文字列 [0..1]
    }

    class EVスタンド_EVChargingStation {
        + 充電種別 / chargeType : 文字列 [0..*]
        + ソケット数 / socketNumber : 数値（物理量） [0..1]
          %% 単位:個
        + ソケット種別 / socketType : 文字列 [0..*]
        + 電圧 / voltage : 数値（物理量） [0..*]
          %% 単位:V
        + 最大電流 / amperage : 数値（物理量） [0..*]
          %% 単位:A
    }

    %% 継承関係
    施設_Facility <|-- ガソリンスタンド_水素ステーション_GasStation : 継承
    ガソリンスタンド_水素ステーション_GasStation <|-- EVスタンド_EVChargingStation : 継承
    駐車場_ParkingFacility <|-- EVスタンド_EVChargingStation : 継承
```

レンタル自転車・eスクータースポット・シェアードカーステーションなどのシェアモビリティスポットは、独自に定義せず[公共交通運行情報標準データ GTFS-JP](https://www.mlit.go.jp/sogoseisaku/transport/sosei_transport_tk_000067.html)で定義される`GBFS(General Bikeshare Feed Specification)`を利用します。
