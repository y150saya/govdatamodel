# 4.4 設備クラス図

設備モデルを「共通基盤」と「ドメイン別継承関係」に分けて定義します。

## 4.4.1 共通基盤（Base & Components）

すべての設備の基底となるクラスと、その構成要素となるクラスの定義です。

```mermaid
classDiagram
    direction TB   

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }

    %% ---------------------------------------------------------
    %% 設備共通（Base Class）
    %% ---------------------------------------------------------
    class 設備_Equipment {
        + ID / id : ID（文字列） [0..1]
        + 設備種別 / equipmentType : コード（文字列） [0..*]
          %% CityGML2.0 AnnexC.4、公共測量標準図式コードの種別情報の利用を想定。
        + 名称 / name : 多言語表記型_Multilingual [1]
        + 説明 / description : 文字列 [0..1]
        %% + 状態 / status : 文字列 [0..1]
        + 利用可能曜日 / availableDay : 文字列 [0..*]
        + 開始時刻 / startTime : 時刻 [0..*]
        + 終了時刻 / endTime : 時刻 [0..*]
        + 利用可能日時説明 / availabileDateTimeDescription : 文字列 [0..1]
        + 利用可能日時 / availableDateTime : 日時 [0..1]
        + 使用可否 / availability : コード（文字列） [0..1] 
          %% 場外を使用可否で単純化。取替中など一時的に使用ができない理由が、備考で記載を想定。
        + 一般利用可否 / generalUserAvailability : コード（文字列） [0..1]
        + 設置位置 / installationLocation : 位置情報型 [0..1]
          %% 各設備に記載するか要調整。 UML記載時はRelationのみの対応。     
        + URL / url : URI [0..1]
        + 備考 / remark : 文字列 [0..1]
    }

    %% ---------------------------------------------------------
    %% 共通パーツ（Components）
    %% ---------------------------------------------------------
    namespace 共通クラス {
        class 住所_Address
        class 連絡先_ContactPoint
        class 施設_Facility
        class 建物_Building
        class 関連組織_RelatedOrganization
        class アクセシビリティ_Accessibility

        class 多言語表記型_Multilingual <<DataType>> {
            + 日本語 / ja : 文字列 [1]
            + カナ / kana : 文字列 [0..1]
            + 英字 / en : 文字列（半角） [0..1]
        }

        class 位置情報型_CommonLocation {
            + 位置 / locationPoint : ジオメトリ(点)  [0..1]
              %% geo:geometry、GeoJSONを基本とする。
            + 階数 / level : 数値（物理量） [0..1]
              %% 単位:階
            + 標高 / elevation : 数値（物理量） [0..1]
              %% 単位:m 
            + 位置説明 / locationDescription : 文字列 [0..1]
        }
    }

    %% ---------------------------------------------------------
    %% コード_リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 可否コード_AvailabilityCode <<Enumeration>> {
            0 : 否
            1 : 可
            2 : 非公開
            9 : 不明
        }
    }

    %% リレーション
    AbstractSmartCityBase <|-- 設備_Equipment
    設備_Equipment *-- "0..1" 住所_Address : 設備住所_equipmentAddress
    設備_Equipment *-- "0..*" 連絡先_ContactPoint : 連絡先情報
    設備_Equipment --> "0..*" 施設_Facility : 関連施設_relatedFacility
    設備_Equipment --> "0..*" 建物_Building : 関連建物_relatedBuilding
    設備_Equipment *-- "0..*" 関連組織_RelatedOrganization : 関連組織情報
    設備_Equipment *-- "0..*" アクセシビリティ_Accessibility : アクセシビリティ情報
    設備_Equipment "1" --> "0..1" 可否コード_AvailabilityCode : 使用可否参照
    設備_Equipment "1" --> "0..1" 可否コード_AvailabilityCode : 一般利用可否参照
    設備_Equipment "1" *--> "0..*" 多言語表記型_Multilingual : 内包
    設備_Equipment "1" *--> "0..1" 位置情報型_CommonLocation : 位置情報参照
```

## 4.4.2 ドメイン別継承関係

### 4.4.2.1 施設系設備　出入口、公衆トイレ

```mermaid
classDiagram
    direction TB
    class 施設_Facility

    class 出入口_Entrance {
        施設_Facility
        + 名称 / name : 文字列 [0..1]
        + 利用開始時刻 / useStartTime : 時刻 [0..*]
          %% 施設の利用時間と別に開門・開扉時間を記載。
        + 利用終了時刻 / useEndTime : 時刻 [0..*]
          %% 施設の利用時間と別に閉門・閉扉時間を記載。
        + 設置位置 / installationLocation : 位置情報型 [0..1]
          %% 共通基盤の施設に記載を基本とする。要調整。UML記載時はRelationのみの対応。
        %% + 緯度 / latitude : 数値（実数） [0..1]
        %% + 経度 / longitude : 数値（実数） [0..1]
        + 出入口区分 / entranceCategory : 文字列 [0..1]
        + 車高制限 / vehicleHeightLimit : 数値（物理量） [0..1]
          %% 単位:m
        + 車幅制限 / vehicleWidthLimit : 数値（物理量） [0..1]
          %% 単位:m
        + 備考 / remark : 文字列 [0..1]
    }

    class 公衆トイレ_PublicToilet {
        施設_Facility
        %% 利用種別トイレおよび付属設備は施設-アクセシビリティによる。
        + 男性トイレ総数 / totalMaleToilet : 数値（物理量） [0..1]
          %% 単位:個
        + 男性小便器数 / urinalMaleToilet : 数値（物理量） [0..1]
          %% 単位:個
        + 女性トイレ総数 / totalFemaleToilet : 数値（物理量） [0..1]
          %% 単位:個
        + 男女共用トイレ総数 / unisexToilet : 数値（物理量） [0..1]
          %% 単位:個
        + バリアフリートイレ数 / numberOfMultipurposeToilet : 数値（物理量） [0..1]
          %% 単位:個
    }

    %% ---------------------------------------------------------
    %% 共通パーツ（Components）
    %% ---------------------------------------------------------
    namespace 共通クラス {
        class 位置情報型_CommonLocation {
            + 位置 / locationPoint : ジオメトリ（点）  [0..1]
              %% geo:geometry、GeoJSONを基本とする。
            + 階数 / level : 数値（物理量） [0..1]
              %% 単位:階
            + 標高 / elevation : 数値（物理量） [0..1]
              %% 単位:m 
            + 位置説明 / locationDescription : 文字列 [0..1]
        }
    }

    namespace コード_リスト定義 {
        class 出入口区分_EntranceCategoryCode <<CodeList>> {
            入口
            出口
            出入口
            搬出入口
        }
    }

    %% リレーション
    出入口_Entrance "1" --> "0..1" 出入口区分_EntranceCategoryCode : 出入口区分参照
    出入口_Entrance "1" *--> "0..1" 位置情報型_CommonLocation : 設置位置参照

    %% 汎化（UML準拠継承）
    施設_Facility <|-- 出入口_Entrance : 継承
    施設_Facility <|-- 公衆トイレ_PublicToilet : 継承
```

### 4.4.2.2 設備　AED、公衆無線LANアクセスポイント、消防水利施設

```mermaid
classDiagram
    direction TB
    class 設備_Equipment

    class AED_AED {
        設備_Equipment
        %% + 設置位置 / installationLocation : 文字列 [0..1]
          %% 共通基盤の設備に記載を基本とする。要調整。
        + 画像 / image : URI [0..1]
        + 外部利用可否 / externalUseAvailability : コード（文字列） [0..1]
    }

    class 公衆無線LANアクセスポイント_PublicWifiAccessPoint {
        設備_Equipment
        + SSID / ssid : ID（文字列） [0..1]
        + 提供エリア / providerItem : 文字列 [0..1]
        + URL / url : URI [0..1]
    }

    class 消防水利施設_FirefightingWaterSupply {
        設備_Equipment
        + 種別 / type : 文字列 [0..1]
        + 口径 / diameter : 数値（物理量） [0..1]
          %% 単位:mm
    }

    %% ---------------------------------------------------------
    %% コード_リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 可否コード_AvailabilityCode <<Enumeration>> {
            0 : 否
            1 : 可
            2 : 非公開
            9 : 不明
        }

        class 消防水利施設種別_FirefightingWaterSupplyType <<CodeList>> {
            %% ※詳細は総務省消防庁の消防水利の基準（昭和三十九年十二月十日消防庁告示第七号）(自治体標準オープンデータセット)
            消火栓
            私設消火栓
            防火水そう
            プール
            河川・溝等
            濠・池等
            海・湖
            井戸
            下水道
            その他
        }
    }

    %% リレーション
    AED_AED "1" --> "0..1" 可否コード_AvailabilityCode : 外部利用可否参照
    消防水利施設_FirefightingWaterSupply "1" --> "0..1" 消防水利施設種別_FirefightingWaterSupplyType : 種別参照

    %% 汎化（UML準拠継承）
    設備_Equipment <|-- AED_AED : 継承
    設備_Equipment <|-- 公衆無線LANアクセスポイント_PublicWifiAccessPoint : 継承
    設備_Equipment <|-- 消防水利施設_FirefightingWaterSupply : 継承
```
