# 4.14 健康情報クラス図

健康情報モデルを「共通基盤」および「ドメイン別継承関係」に分けて定義します。
健康情報および給食情報は外部のデータ標準・オープンデータ仕様を参照することを想定しており、本モデルはこれらとの対応関係を示します。

## 4.14.1 共通基盤

健康情報モデルおよび給食情報モデルの基本クラスは、基本共通クラスである `AbstractSmartCityBase` を継承します。

```mermaid
classDiagram
    direction TB

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }
```

---

## 4.14.2 ドメイン別継承関係

### 4.14.2.1 健康情報

* 健康情報は[HL7 FHIR JP Core](https://jpfhir.jp/fhir/core/history.html)のJP_Observation_Commonもしくは[Fast Healthcare Interoperability Resource HL7 FHIR](http://hl7.org/fhir/)のObservationを参照することができます。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    %% ---------------------------------------------------------
    %% クラス定義
    %% ---------------------------------------------------------
    class 健康情報_HealthInformation {
        <<External>>
        %% HL7 FHIR JP Core : JP_Observation_Common
        %% HL7 FHIR : Observation
    }

    %% ---------------------------------------------------------
    %% 外部参照規格（External Standards）
    %% ---------------------------------------------------------
    namespace HL7_FHIR_JP_Core {
        class JP_Observation_Common {
            参考のため、実際のクラス図では削除する。
            https://jpfhir.jp/fhir/core/1.2.0/StructureDefinition-jp-observation-common.html
            + 識別子 / identifier : Identifier [0..*]
            + 状態 / status : code [1..1]
            + カテゴリ / category : CodeableConcept [0..*]
            + 観察コード / code : CodeableConcept [1..1]
            + 対象 / subject : Reference [0..1]
              %% 患者(Patient)、グループ(Group)、デバイス(Device)、場所(Location)への参照
            + 実施日時 / effectiveDateTime : dateTime [0..1]
            + 実施期間 / effectivePeriod : Period [0..1]
            + 値 / valueQuantity : Quantity [0..1]
            + 値 / valueCodeableConcept : CodeableConcept [0..1]
            + 値 / valueString : string [0..1]
            + 値 / valueBoolean : boolean [0..1]
            + 値 / valueInteger : integer [0..1]
            + 値 / valueRange : Range [0..1]
            + 値 / valueRatio : Ratio [0..1]
            + 値 / valueSampledData : SampledData [0..1]
            + 値 / valueTime : time [0..1]
            + 値 / valueDateTime : dateTime [0..1]
            + 値 / valuePeriod : Period [0..1]
            + 欠損理由 / dataAbsentReason : CodeableConcept [0..1]
            + 基準範囲 / referenceRange : ObservationReferenceRange [0..*]
            + 備考 / remark : Annotation [0..*]
        }
    }

    %% 汎化（継承関係）
    AbstractSmartCityBase <|-- 健康情報_HealthInformation : 継承

    %% 参照関係
    健康情報_HealthInformation "1" ..> "0..*" JP_Observation_Common : 参照（HL7 FHIR）
```

### 4.14.2.2 給食情報

* 給食情報は[デジタル庁 自治体標準オープンデータセット](https://www.digital.go.jp/resources/open_data/municipal-standard-data-set-test)の学校給食献立情報を参照することができます。

### 4.14.2.2.1 通常データモデル

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    %% ---------------------------------------------------------
    %% クラス定義
    %% ---------------------------------------------------------
    class 給食情報_SchoolLunch {
        <<External>>
        %% デジタル庁 自治体標準オープンデータセット 学校給食献立情報
    }

    %% ---------------------------------------------------------
    %% 外部参照規格（External Standards）
    %% ---------------------------------------------------------
    namespace デジタル庁_自治体標準オープンデータセット {
        class 学校給食献立情報_SchoolLunch {
            参考のため、実際のクラス図では削除する。
            https://www.digital.go.jp/resources/open_data/municipal-standard-data-set-test
            %% 学校情報
            + 管理主体全国地方公共団体コード / managementLocalGovernmentCode : コード（文字列） [0..1]
            + 学校ID / schoolId : ID(文字列) [0..1]
            %% 管理主体が発行する学校の一意な識別キー
            + 学校コード / schoolCode : コード（文字列） [0..1]
            %% 文科省・教育データ標準の13桁の学校コード
            + 所在地全国地方公共団体コード / locationLocalGovernmentCode : コード（文字列） [0..1]
            + 所在地都道府県 / locationPrefecture : 文字列 [0..1]
            + 所在地郡 / locationCounty : 文字列 [0..1]
            + 所在地市区町村 / locationCity : 文字列 [0..1]
            + 所在地政令市区 / locationWard : 文字列 [0..1]
            + 学校名 / schoolName : 多言語表記型_Multilingual [0..1]
            + 対象学年 / grade : 文字列 [0..*]
            %% 学年ごとに給食が分かれている場合、提供対象学年の数字を";"区切りで列挙する。
            + レコードID / recordId : ID(文字列) [0..1]
            + 提供年月日 / date : 日付 [0..1]
            + 献立ID / menuId : ID(文字列) [0..1]
            + 料理ID / dishId : ID(文字列) [0..*]
            + 料理名 / dishName : 文字列 [0..1]
            + 同一料理内番号 / sequentialNumber : 数値（整数） [0..1]
              %% 料理IDが同じ場合、この番号で料理を区別する。
            + 食品ID / foodId : ID(文字列) [0..*]
            + 成分表食品名 / foodName : 文字列 [0..*]
            + 独自食品名 / customFoodName : 文字列 [0..*]
            + 食品群6群 / foodGroup6 : 数値(整数) [0..*]
            + 食品群3群 / foodGroup3 : 文字列 [0..*]
            + 分量 / quantity : 数値（物理量） [0..1]
              %% 単位: g
            + エネルギー量 / energy : 数値（物理量） [0..1]
              %% 単位: kcal
            + たんぱく質 / protein : 数値（物理量） [0..1]
              %% 単位: g
            + タンパク質エネルギー比 / proteinEnergyRatio : 数値（物理量） [0..1]
              %% 単位: %E
            + 脂質 / fat : 数値（物理量） [0..1]
              %% 単位: g
            + 脂質エネルギー比 / fatEnergyRatio : 数値（物理量） [0..1]
              %% 単位: %E
            + 食塩相当量 / saltEquivalent : 数値（物理量） [0..1]
              %% 単位: g
            + カルシウム / calcium : 数値（物理量） [0..1]
              %% 単位: mg
            + マグネシウム / magnesium : 数値（物理量） [0..1]
              %% 単位: mg
            + 鉄 / iron : 数値（物理量） [0..1]
              %% 単位: mg
            + 亜鉛 / zinc : 数値（物理量） [0..1]
              %% 単位: mg
            + ビタミンA_ug / vitaminA_ug : 数値（物理量） [0..1]
              %% 単位: μg
            + ビタミンA_ugRAE / vitaminA_ugrae : 数値（物理量） [0..1]
              %% 単位: μgRAE
            + ビタミンA_IU / vitaminA_IU : 数値（物理量） [0..1]
              %% 単位: IU
            + ビタミンB1 / vitaminB1 : 数値（物理量） [0..1]
              %% 単位: mg
            + ビタミンB2 / vitaminB2 : 数値（物理量） [0..1]
              %% 単位: mg
            + ビタミンC / vitaminC : 数値（物理量） [0..1]
              %% 単位: mg
            + 食物繊維 / dietaryFiber : 数値（物理量） [0..1]
              %% 単位: g
            + 炭水化物 / carbohydrate : 数値（物理量） [0..1]
              %% 単位: g
            + 糖質量 / sugarContent : 数値（物理量） [0..1]
              %% 単位: g
            + アレルゲン情報公開有無 / openAllergenInformation : コード（文字列） [0..1]
            + アレルゲン品目 / allergenItem : 文字列 [0..*]
            + 料理単位調理方法 / cookingMethodDish : 文字列 [0..*]
            + 食材単位調理方法 / cookingMethodIngredient : 文字列 [0..*]
            + 備考 / remark : 文字列 [0..1]
        }
    }

    %% 汎化（継承関係）
    AbstractSmartCityBase <|-- 給食情報_SchoolLunch : 継承

    %% 参照関係
    給食情報_SchoolLunch "1" ..> "0..*" 学校給食献立情報_SchoolLunch : 参照（デジタル庁）
    学校給食献立情報_SchoolLunch "1" --> "0..1" 有無コード_StatusCode : アレルゲン情報公開有無
```
