# 4.1 土地クラス図

土地モデルを「共通基盤」と「ドメイン別関係」に分けて定義します。

## 4.1.1 共通基盤（Base & Components）

すべての土地の基底となる共通クラスの定義です。

```mermaid
classDiagram
    direction TB

    %% ---------------------------------------------------------
    %% 共通基底クラス
    %% ---------------------------------------------------------
    class AbstractSmartCityBase {
        + 識別子 / identifier : 文字列 [1]
        + 名称 / name : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
    }
```

---

## 4.1.2 ドメイン別関係

### 4.1.2.1 土地モデル

土地の物理的な範囲・形状、用途、付随する住所や連絡先情報、および関連する各種コードリストの定義です。
* 土地の用途区分は、[都市計画基礎調査実施要領](https://www.mlit.go.jp/toshi/tosiko/kisotyousa001.html)の土地利用現況の土地利用分類を参照して定義します。

```mermaid
classDiagram
    direction TB
    class AbstractSmartCityBase

    %% ---------------------------------------------------------
    %% クラス定義
    %% ---------------------------------------------------------
    class 土地_Land {
        + ID / id : ID（文字列） [0..1]
          %% 土地を一意に識別するIDで土地単位に附番を想定。筆ごとの場合は法務省の不動産登記規則に基づく13桁の不動産番号が利用できる。この場合、将来は不動産ID（17桁）の利用も想定できる。
        + 土地用途 / landUsage : コード（文字列） [1..*]
          %% 国土交通省都市局の都市計画基礎調査実施要領の土地利用現況の土地利用分類
        + 名称 / name : 多言語表記型_Multilingual [0..1]
        + 通称 / alternateName : 文字列 [0..1]
        + 説明 / description : 文字列 [0..1]
        + 土地面積 / landArea : 数値(実数) [0..1]
          %% 単位: m2
        + 土地形状イメージURL / landFormImageUrl : URI [0..1]
        + 備考 / remark : 文字列 [0..1]
        %% 将来 + 不動産ID / realEstateId : ID（文字列） [0..1]
          %% ※国土交通省「不動産IDルールガイドライン」に準拠した17桁のコード
          %% （法務省の不動産登記規則に基づく13桁の不動産番号 ＋ 特定コード4桁）
        %% --- 地理空間座標属性 ---
        %% 空間スキーマ型に座標参照系と座標参照系コードを組み入れて、関連させるか要検討。
        + 土地形状 / landForm : ジオメトリ（面2D） [0..1]
        %% + 座標参照系 / coordinateReferenceSystem : 文字列 [0..1]
        %% + 座標参照系コード / coordinateReferenceSystemCode : コード（文字列） [0..1]
    }

    %% ---------------------------------------------------------
    %% コード・リスト定義クラス
    %% ---------------------------------------------------------
    namespace コード_リスト定義 {
        class 土地コード_LandCode <<CodeList>> {
            %% 国土交通省都市局の都市計画基礎調査実施要領の土地利用現況の土地利用分類
            201 : 田（水田）
            202 : 畑（畑、樹園地、採草地、養鶏（牛・豚）場）
            203 : 山林（樹林地）v
            204 : 水面（河川水面、湖沼、ため池、用水路、濠、運河水面）
            205 : その他自然地（原野・牧野、荒れ地、低湿地、河川敷・河原、海浜、湖岸）
            211 : 住宅用地（住宅、共同住宅、店舗等併用住宅、店舗等併用共同住宅、作業所併用住宅）
            212 : 商業用地
            213 : 工業用地
            219 : 農林漁業施設用地
            214 : 公益施設用地
            215 : 道路用地（道路、駅前広場）
            216 : 交通施設用地
            217 : 公共空地（公園・緑地、広場、運動場、墓園）
            218 : その他公的施設用地（防衛施設用地）
            219 : その他①（ゴルフ場）
            220 : その他空地②（太陽光発電のシステムを直接整備している土地）
            221 : その他の空地③（平面駐車場）
            222 : その他の空地④（その他の空地①～③以外の都市的土地利用：建物跡地、資材置場、改変工事中の土地、法面（道路、造成地等の主利用に含まれない法面））
            223 : 不明
            224 : 低未利用土地(用途に供されていない空地、空家・空店舗・空施設の存する土地等)
        }
    }

    namespace 共通クラス {
        class 住所_Address
        class 連絡先_ContactPoint

        %% 共通の構造体（言語）
        class 多言語表記型_Multilingual <<DataType>> {
            + 日本語 / ja : 文字列 [1]
            + カナ / kana : 文字列 [0..1]
            + 英字 / en : 文字列（半角） [0..1]
        }
    }

    %% 汎化（継承）
    AbstractSmartCityBase <|-- 土地_Land : 継承

    %% コンポジション（関係性の定義）
    土地_Land *-- "1" 住所_Address : 土地住所_landAddress
    土地_Land *-- "0..1" 連絡先_ContactPoint : 連絡先情報_contactPoint
    土地_Land "1" *-- "0..*" 多言語表記型_Multilingual : 名称

    %% リレーション
    土地_Land "1" --> "1..*" 土地コード_LandCode : 土地用途_landUsage
```
