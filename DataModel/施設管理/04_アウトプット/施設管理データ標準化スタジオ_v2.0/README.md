# 施設管理データ標準化スタジオ v2.0

自治体施設管理データモデルの業務領域・基本データセット定義（9テーブル）、クラス図対応の共通クラス定義（12クラス）、Mermaidクラス図（全体関連図・6領域の簡易/詳細クラス図）、統制語彙・コード定義、同義語詳細辞書を統合した標準化ワークベンチです。

`v1.0` を安定版スナップショットとして保持したうえで、`v2.0` では **クラス図対応共通クラスを取り込んだ `施設管理データモデル.csv` への対応**、**`07_論理クラス図` のMermaidクラス図ビューア搭載**、および **画面テキストの設定ファイル分離（`ui_texts.json`）** を行っています。

## すぐ開く・配布する方法（サーバー不要）

エクスプローラー等から以下の単一HTMLファイルをそのままブラウザ（Edge / Chrome 等）で開いてください。関係者に共有する際も、**この1ファイルをコピーして渡すだけ**で同じ画面を閲覧できます。

- **`dist/standalone.html`**（HTML・CSS・JavaScript・全モデルデータ・Mermaidクラス図定義・画面文言を1ファイルに同梱）

## v2.0 の主な特長

1. **基本データセット（9表）と共通クラス（12種）の整理・相互参照**
   - 実務運用・CSV入出力の基本となる **9テーブル** を維持しつつ、データモデルに定義された **12の共通クラス（建物・土地・住所・連絡先・スケジュール・関連組織情報型・駐車場・アクセシビリティ・画像・位置情報型・空間スキーマ・多言語表記型）** を統合しました。
   - 各項目の **`◇ 関連クラス`** バッジを押すと、対応する共通クラスの属性一覧・逆引き参照元・登場クラス図がその場でポップアップ表示されます。
   - 「領域・項目定義ブラウザ」の **「共通クラス」タブ** から、全12クラスの定義（クラス図でのみ構造展開される `関連組織情報型` を含む）を一覧・検索できます。
2. **`07_論理クラス図/*.md` のMermaidクラス図に連動した関連図ビューア**
   - クラス図フォルダ（`07_論理クラス図`）配下の7ファイル（全体関連図＋領域01〜06の簡易・詳細クラス図、計13図）のMermaid `classDiagram` 定義を自動解析し、外部ライブラリ不要のインタラクティブUMLクラス図（SVG）として描画します。
   - 図の見やすさを保つため、Mermaid内の **`namespace コード定義`（列挙型クラス群）とそこへの関係線を自動除外** して論理クラス構造とコンポジション（`◆`）・多重度を表示します。
   - **「`<>` Mermaidソース表示」モード** では、コード定義除外済みの整形Mermaidソース（または元ソース全文）の閲覧・1クリックコピー・`.mmd` 保存が可能です。
   - 従来の **「基本データセットER図（9表PK/FK）」** ともワンクリックで切り替えられます。
3. **画面文言・説明文の設定ファイル分離（`ui_texts.json`）**
   - トップ画面のタイトル・リード文、各業務領域（01〜06）、各テーブル、および各共通クラスの説明文を `ui_texts.json` で編集できます（空文字 `""` で非表示、`\\n` で改行）。
4. **正本CSV・クラス図Markdown更新への自動追従**
   - `06_データモデルCSV` 配下のCSVやクラス図配下の `.md` を更新して `generate_data.py` を実行すると、集計値・項目定義・コード辞書・UMLクラス図へ一括反映されます。

## 文言変更・データ更新時の再ビルド手順

リポジトリ直下またはスクリプトの配置ディレクトリで以下のコマンドを実行すると、`dist/data/model.json`（整形JSON）および `dist/standalone.html` が再生成されます。

```powershell
# 施設管理ディレクトリまたはリポジトリルートから実行
python "DataModel/施設管理/04_アウトプット/施設管理データ標準化スタジオ_v2.0/generate_data.py"
```

> **注意**：`dist/standalone.html` には改ざん・XSS防止用のスクリプトハッシュ（CSP SHA-256）が埋め込まれているため、`standalone.html` を直接書き換えず、`ui_texts.json`・`06_データモデルCSV`・クラス図マークダウンを編集してから `generate_data.py` を実行してください。

## ファイル構成

- `ui_texts.json`：**【文言編集用】** 画面タイトル・見出し・領域/テーブル/共通クラス説明文の設定ファイル
- `generate_data.py`：`06_データモデルCSV`・`07_論理クラス図`・`ui_texts.json` を読み込み、`dist/` 配下を一括生成するビルドスクリプト
- `dist/standalone.html`：**【配布・閲覧用】** 単一ファイル完結版（SHA-256 Content-Security-Policy 付き）
- `dist/index.html` / `dist/style.css` / `dist/app.js`：画面テンプレート・スタイル・UIロジックのソース
- `dist/data/model.json`：生成データの整形JSON（確認用・2スペースインデント付き）
- `dist/data/model-data.js`：`index.html` 用の同梱スクリプトバンドル

## セキュリティ・動作前提

- 外部API、CDN、外部Webフォント、生成AI通信、解析スクリプト等は一切使用しません。
- `standalone.html` には外部通信を遮断する `Content-Security-Policy`（`default-src 'none'; connect-src 'none';` およびインラインスクリプトのSHA-256ハッシュ指定）を設定しています。
