## 2. 重複・類似語彙（一般設備 vs 防災・バリアフリー特化設備）の使い分けとデータ連携ルール

「官庁営繕（設備保全の観点）」と「内閣府EEI（避難所の災害対応観点）」「スマートシティ・アクセシビリティ（利用者案内の観点）」を統合しているため、一部に包含・類似関係にある語彙が存在する。二重登録や選択の迷いを防ぐため、以下の使い分け基準とデータ連携ルールを適用する。

### ① 空調系：`空気調和設備` と `冷房設備`・`暖房設備` の使い分け
- **背景**：官庁営繕では冷暖房兼用の空調機器やシステム一式を「空気調和設備」として管理する一方、内閣府EEI（避難所）では学校の体育館等で「冬場のストーブ・床暖房のみ（冷房なし）」「夏場のスポットクーラー・冷房専用機のみ」のケースが多いため、「冷房設備」「暖房設備」を分けて把握。
- **登録・選択ルール**：
  1. **`空気調和設備`**（No.20）：**【原則はこちらを選択】** 冷房・暖房の両機能を備えた一般的なエアコン（パッケージエアコン、ルームエアコン、ビル用マルチ等）や建物全体の空調システム一式。**これを登録した場合、`冷房設備` と `暖房設備` に分けて二重登録する必要はない。排他関係**
  2. **`冷房設備`**（No.23）：**冷房機能のみ**を持つ単機能設備（冷房専用エアコン、スポットクーラー等）、または避難所管理等で冷房機能を単独で登録・管理する場合に選択する。
  3. **`暖房設備`**（No.24）：**暖房機能のみ**を持つ単機能設備（FF式ストーブ、温風暖房機、ジェットヒーター、床暖房等）、または避難所管理等で暖房機能を単独で登録・管理する場合に選択する。
  4. **`冷温熱源設備`**（No.21）・**`冷却塔設備`**（No.22）：ボイラー・チラー（冷温水発生機）や冷却塔（クーリングタワー）など、法定点検（ボイラー性能検査、建築物衛生法の冷却塔清掃、ばい煙測定等）の対象となる熱源・冷却塔機器を空調システムから独立して台帳管理する場合に選択する（空調システムの `EquipmentUnit` として下位登録してもよい）。
- **データ連携ルール（内閣府EEI等への出力時）**：
  - 施設に **`空気調和設備`** が登録（稼働可）されている場合は、内閣府EEIの **「冷房設備：有（使用可）」かつ「暖房設備：有（使用可）」の両方を満たす**ものとして自動判定・変換する。

### ② 水槽系：`受水槽・高置水槽` と `耐震性貯水槽` の使い分け
- 一般的な飲料水・雑用水の給水タンク（水道法第34条の簡易専用水道検査対象等）は **`受水槽・高置水槽`**（No.29）を選択する。
- 災害時の飲料水確保等を目的とした緊急遮断弁付の耐震貯水槽（内閣府EEI対象）は **`耐震性貯水槽`**（No.30）を選択する。

### ③ 昇降機系：`エレベータ` と `バリアフリー対応エレベーター` の使い分け
- 一般的な乗用・人荷用・寝台用エレベーターは **`エレベータ`**（No.57）を選択する。車椅子対応操作盤・鏡・音声案内等を備えたエレベーターを独立して登録する場合は **`バリアフリー対応エレベーター`**（No.58）を選択する。
- 給食室や図書館等の荷物搬送用で建築基準法第12条点検の対象となるものは **`小荷物専用昇降機`**（No.61）を選択する。

### ④ トイレ系：`トイレ` と `バリアフリートイレ`・`子供トイレ`・`乳児用設備対応トイレ` の使い分け
- 館内の一般便所や屋外の公衆トイレ全体は **`トイレ`**（No.37）を選択する。
- 車椅子使用者用・オストメイト用・幼児用便器・乳児用設備等を備えた特化トイレを一般トイレとは別レコードとして件数・設置階ごとに管理・案内する場合は **`バリアフリートイレ`**（No.38）、**`子供トイレ`**（No.39）、**`乳児用設備対応トイレ`**（No.40）を選択する。
